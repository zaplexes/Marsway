# AI use in Marsway

Marsway is an **AI-assisted project**. ChatGPT and OpenAI Codex were used throughout planning, research, design, implementation, debugging, testing, documentation and presentation production. This disclosure covers team-authored work across the repository, not the authorship of external scientific sources or third-party software.

| Area                        | How AI was used                                                                                                                                                | Identification                                                                                |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Ideas and architecture      | Exploring requirements, user journeys, technical approaches and implementation plans                                                                           | This document and project documentation                                                       |
| Research and interpretation | Finding sources, summarizing publications, discussing scientific limitations and developing processing methods                                                 | Source links and limitations accompany the scientific evidence                                |
| Code                        | Generating and editing application, game, pipeline, build and test code; debugging and validation                                                              | Source notices, package metadata and the public disclosure manifest                           |
| Data processing             | AI-assisted code imports source records and derives terrain displays and context samples from cited datasets                                                   | Dataset provenance remains attached to each product; source observations are not AI-generated |
| Writing and translation     | Interface copy, documentation, diagrams, submission drafts, captions and narration scripts                                                                     | App/documentation notices and diagram labels                                                  |
| Visual design and logo      | AI-assisted interface design; the Marsway emblem was generated with OpenAI image generation                                                                    | Visible logo labels and a labeled SVG for sharing                                             |
| Game                        | AI-assisted implementation of procedural fictional terrain, arcade motion, route conversion and game text                                                      | The game labels its AI-assisted code and fictional terrain                                    |
| Presentation                | AI-assisted script, recording automation, editing and original procedural ambience; English speech generated with the `en-US-GuyNeural` voice through edge-tts | Persistent video watermark, descriptive credits and media metadata                            |

NASA, JPL, USGS, IAU, ESA and other credited organizations retain authorship of their imagery, observations, catalogues and published scientific products. These records are not labeled as AI-generated. Terrain colours and sparse context samples are local computational derivatives, not new scientific measurements produced by a language model. Third-party software retains its own authorship and licenses.

The rover game's terrain, compressed distances and discoveries are fictional. Preference-based destination scores are decision-support heuristics. Neither AI assistance nor successful software tests establish scientific validity, terrain access or a safe route. The team remains responsible for reviewing the work and describing its limitations accurately.

The app and static documentation link to the machine-readable [AI disclosure manifest](assets/ai-disclosure.json), published at `https://zaplexes.github.io/Marsway/ai-disclosure.json`. The final presentation with a persistent watermark is `artifacts/marsway-video-updated/marsway-30s-ai-watermark.mp4`.
